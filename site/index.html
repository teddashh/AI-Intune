The problem 真正的問題

AI work fails quietly.

AI 工作最常安靜地失敗。

A living process is not a healthy agent. A completed command is not a successful deployment. AI-Intune turns claims into inspectable evidence.

Process 還活著，不代表 agent 正常；指令執行完，不代表部署成功。AI-Intune 把每一個成功宣告都變成可檢查的證據。

The useful question is not “did the command run?” It is “what proves the machine reached the intended state?”
真正有用的問題不是「指令有沒有跑」，而是「什麼證明機器已經到達預期狀態？」
One path to managed 一條完整納管路徑

From a fresh machine to verified state.

從新機器一路到完成驗證。

Install the Hub once. Every new endpoint follows the same repeatable enrollment and profile-assignment workflow.

主控端只需安裝一次。之後每一台新端點都走相同、可重複的註冊與 profile 指派流程。

01

Install the Hub

安裝主控端

Build the static Hub and architecture-specific Agent bundles, then bind the control plane to the tailnet.

建立靜態 Hub 與分架構 Agent bundle，並將控制平臺綁定在 tailnet。

02

Enroll one machine

註冊一台機器

A one-time token and self-contained bundle install Tailscale, the Agent, rootless Podman, fixed app services, identity, and the job channel.

一次性 token 與自含 bundle 會安裝 Tailscale、Agent、rootless Podman、固定 app services、機器身分與工作通道。

03

Assign a profile

指派機器 Profile

Select OpenClaw or Hermes. The resolver adds exact dependencies and can replace the machine's current primary runtime.

選擇 OpenClaw 或 Hermes；resolver 會補齊精確依賴，也能取代機器目前的 primary runtime。

04

Verify the result

驗證最終結果

The Agent verifies artifact bytes, exact versions, activation, and runtime health before the Hub marks the assignment complete.

Agent 會驗證 artifact bytes、精確版本、啟用狀態與 runtime 健康，Hub 才會將指派標記為完成。

The check-in is proof

check-in 才是回執

The one-time token is never part of the install command.

一次性 token 不會寫在安裝指令裡。

The old one comes back

失敗就換回舊的

Both OpenClaw and Hermes record the previous runtime before they try the new one.

OpenClaw 和 Hermes 都會先把舊的 runtime 記下來，再去試新的。

Control-plane essentials 控制平臺核心能力

Built for facts, not hopeful green lights.

管理的是事實，不是令人安心的綠燈。

Every visible state connects back to machine identity, immutable desired state, execution, verification, and audit evidence.

每一個畫面上的狀態，都能追溯到機器身分、不可變 desired state、執行結果、驗證與稽核證據。

01

Fleet truth

機隊真實狀態

A named machine roster, check-in ledger, health facts, credential state, change reports, and evidence drill-downs.

具名機器清單、check-in ledger、健康資訊、憑證狀態、變更報告與逐層證據檢視。

02

Content-addressed Store

內容定址的 Store

Artifacts are admitted by exact SHA-256 and size, then bound to immutable manifests and typed Agent adapters.

Artifact 以精確 SHA-256 與大小收錄，再綁定至不可變 manifest 與具型別的 Agent adapter。

03

Dependency-aware profiles

理解依賴的 Profile

Profiles select exact apps. The Hub resolves runtimes, platform support, conflicts, and a stable execution order.

Profile 選定精確 app；Hub 解析 runtime、平臺支援、衝突與穩定執行順序。

04

Controlled execution

受控執行

Leased jobs, prerequisite edges, time bounds, retries, deterministic failure propagation, and ordered revisions.

具 lease 的 job、前置依賴、時間界線、重試、確定性的失敗傳遞與 revision 順序。

05

Verified outcomes

已驗證的結果

Success means the expected files, exact version, activation target, and runtime checks all passed, not merely that a command exited.

成功代表預期檔案、精確版本、啟用目標與 runtime 檢查全部通過，而不只是指令離開。

06

Auditable operations

可稽核的操作

Preview/apply digests, idempotency receipts, append-only assignment history, and recovery records make each change traceable.

Preview/apply digest、冪等收據、append-only 指派歷史與 recovery record，讓每次變更都可追溯。

Wait when Hub is busy

Hub 忙就再等

If renewing the lease is refused, the adapter is cancelled.

續租失敗的話，Agent 會把轉接器停掉。

Architecture 系統架構

Small enough to own. Strict enough to trust.

規模足以掌握，規則足以信任。

One Go Hub, one static Go Agent per endpoint, SQLite as the control ledger, and Tailscale as the private network and operator identity boundary.

一個 Go Hub、每端點一個靜態 Go Agent、SQLite 控制 ledger，以及作為私有網路與 operator 身分邊界的 Tailscale。

The management boundary is a product feature.

清楚的管理邊界，本身就是產品能力。

  • Endpoints open no inbound control port
  • 端點不開放任何 inbound 控制 port
  • OAuth tokens and API keys stay endpoint-local
  • OAuth token 與 API key 留在端點本機
  • The Hub never proxies AI model traffic
  • Hub 不代理任何 AI model 流量
  • Package jobs select typed adapters, not arbitrary shell
  • 套件 job 選擇 typed adapter，不下發任意 shell
  • Mutations are previewed, confirmed, idempotent, and audited
  • 變更皆經 preview、確認、冪等處理與稽核

Hub asks Tailscale

Hub 問 Tailscale

The Hub does not take the caller's word for who the admin is. It asks Tailscale about this connection.

管理者是誰，Hub 不聽呼叫端自己說，而是請 Tailscale 查這次連線。

One writer, then busy

寫入排太久，就回忙碌

The Hub keeps its data in SQLite, which takes one write at a time.

Hub 的資料在 SQLite，一次只讓一個寫入。

Standard Store 標準 Store

Choose the app. Resolve the machine.

選好應用，系統補齊整台機器。

The built-in catalog deploys Node runtime, OpenClaw, and Hermes on Linux amd64 and arm64. OpenClaw resolves its exact Node dependency; Hermes resolves its exact official OCI image. Switching profiles stops and disables the old runtime, verifies the new one, and restores the prior runtime if verification fails.

內建 catalog 可在 Linux amd64 與 arm64 部署 Node runtime、OpenClaw 與 Hermes。OpenClaw 會解析精確 Node 依賴；Hermes 會解析精確官方 OCI image。切換 profile 時會停止並停用舊 runtime、驗證新 runtime；驗證失敗則恢復原本的 runtime。
